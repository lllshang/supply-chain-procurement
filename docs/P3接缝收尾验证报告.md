**环境坑（复用必读）**：
1. JDBC URL `characterEncoding=utf8mb4` 非法——mysql-connector-j 只认 Java 字符集名，**用 `UTF-8`**（连接层自动映射 utf8mb4）。
2. **jar 内嵌的 data.sql 是打包时快照**——后提交的菜单种子对旧 jar 不生效；要么重新打包，要么对运行库手工重放种子（INSERT IGNORE 幂等）。
3. 新库模式 = 每次验证新建空库自动初始化，规避老库结构漂移（3307 老 `supply_chain` 库已废弃）。
