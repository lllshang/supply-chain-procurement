## A1【阻塞项·P3c 首项】合同价格清单 + 下单第四重校验（BR-26）

**PRD 依据**：L746"合同供应商、采购项、**价格清单**、合同剩余额度和预算均需校验通过"；L848"合同应维护价格清单…存在报价或定标结果时继承供应商、价格和数量"；L1101 BR-26"合同…价格…必须与订单一致"；L1205 `contract_price_item`；L1207 `purchase_order_item.contract_item_id`。

**现状缺口**：无 `contract_price_item` 实体；`order_item` 无 `contract_item_id`；下单三重校验（申请头闸/余量闸/合同额度闸）缺"价格与合同一致"第四重。

**裁决三条（主理人已确认）**：
1. **价格不一致 = 硬拦截 4000**，无"偏离说明+审核"旁路——BR-26 原文（L1101"必须与订单一致"）无任何例外通道，审计结论不允许加宽；
2. **双来源继承**：签订合同时存在定标结果 → `contract_price_item` 由 `award_item` 单价×数量自动继承生成（R2 单中标口径）；无定标结果（D2 手填/框架）→ 手工维护（表单页签，`type` in FRAME/FIXED/AGREEMENT 时可见）；两者并存时以手工为准；
3. **免检类型**：FRAME_EMPTY（框架协议，仅金额控制无商品明细）跳过第四重校验，走合同额度闸兜底。

**改动面**：
- DDL：新建 `contract_price_item(id, contract_id, sku_id, unit_price, qty, source_type(1继承/2手工), remark, BaseEntity)`；`purchase_order_item` + `contract_item_id BIGINT NULL`
- 服务：合同创建/登记时生成价格清单（继承或接收手工明细）；`createOrder` 校验链加第四重——每行 `order_item` 必须命中 `contract_price_item`（sku+价格一致），未命中或价不符 → 4000 拦截；命中行回填 `contract_item_id`
- 前端：合同详情加"价格清单"页签（只读展示来源标注）；下单报错文案标明"与合同价格清单不一致"
- **AC**：①FIXED 合同下单价格与清单一致 → 成功且 `contract_item_id` 回填；②价格偏离（5980 vs 清单 5680）→ 4000 拦截不落库；③FRAME_EMPTY 合同下单 → 跳过第四重、额度闸生效；④继承生成：定标 2 SKU → 合同价格清单 2 行 source=1 单价与定标一致

## A2 报价含税三件套（S4 + P-5 含税口径）

**PRD 依据**：RFQ-09 L697（校验含税率/运费/交期）；L709（供应商填写**含税单价**和承诺交期）；L711（金额=**含税单价×数量**）；L717（比价维度含税率/运费/交期）；L935（价格库含税价+税率）；L1203（`supplier_quote(tax_rate, freight, delivery_time, …)`）。

**裁决**：`quotation` + `tax_rate DECIMAL(5,2)`、`freight DECIMAL(18,2)`、`delivery_days INT`；**金额统一含税口径：金额 = 含税单价 × 数量**（L711 原文）；**不保留不含税净额字段**（依据：PRD 全文无"不含税"计算要求；P3 成本归集按结算单已落账金额取数与报价解耦；价格库 L935 即含税口径）——成本如未来需净额，经税率换算派生，不双写。比价页展示：含税单价 / 税率 / 运费 / 交期 **并列四维**，综合排序仍按含税总价（单价×数量+运费）。

**改动面**：quotation ALTER +3 列；报价导入模板/校验（三件套必填，税率 0–13 合法域）；比价视图/分析页；定标带价（award 继承含税价）；订单金额计算已按含税价（现状不动，回归确认）；价格库沉淀埋点带税率。

**AC**：①报价导入含税率/运费/交期 → 比价四维并列展示；②含税总价=单价×数量+运费 排序正确；③定标后 award/合同价格清单（A1）继承含税单价与税率；④旧数据（无税率）兼容展示"-"不报错。

## A3 采购申请：用途 / 项目名（S9 剩余）

**PRD 依据**：PR-01 L644（"填写部门、申请人、需求时间、**用途**、预算科目和**手工录入的项目名称**"）；L1199（`purchase_request(need_time, purpose, subject, project)`）；L608-609（项目仅统计归属、**不参与额度**）。

**裁决**：`purchase_apply` + `purpose VARCHAR(200) NOT NULL`、`project_name VARCHAR(120) NULL`——**手工文本，非档案外键**（L608-609：项目仅统计归属，不做项目管理）。`expected_date`≈need_time 已有 ✅、`subject_id` 已落地（QA2-01）✅，勿重复。

**改动面**：DDL +2 列；申请表单（用途必填、项目名选填）；列表/详情/导出带出；预算占用/校验逻辑**不受影响**（项目不入额度）。

**AC**：①缺用途提交 → 校验拒绝；②项目名纯文本入库不关联档案；③导出含两字段；④预算科目占用行为与改造前一致（回归）。

## A4 整单拒收退货（S10 单据级）

**PRD 依据**：L827（状态机"待验收入库→**拒收退货**：全部拒收"）；L809（"整单拒收：全部合格量置 0，差异行选择退货，**必须填写原因并上传凭证**"）；L1115（到货状态全集含"拒收退货"）。

**裁决**：`ArrivalStatus` + `REJECTED_RETURNED(4, "拒收退货")`；新增"整单拒收"动作端点——校验：到货单未入库/部分入库可整拒（已 STORED 不可），**原因+凭证必填**，执行后全部 `arrival_item.qualified_qty=0`、差异行 handle_type=退货、单据状态 → REJECTED_RETURNED。订单侧联动：整拒后订单到货缺口回到可收状态（与现状部分退货口径一致，回归确认）。

**AC**：①整拒（原因+凭证）→ 状态 REJECTED_RETURNED、合格量全 0；②缺原因或凭证 → 拒绝；③已全部入库单据 → 不可整拒（3003）；④整拒后订单可再次到货登记。

## A5 服务扣款明细子表（S11）

**PRD 依据**：L812（"登记验收数量、履约说明和**一条或多条扣款明细**；扣款项目取**服务考核指标**，扣款金额不得导致应付为负"）；L879-880；BR-15 L1090。

**裁决**：新建 `service_deduction_item(id, assess_id, item_name VARCHAR(100) COMMENT '考核指标', amount DECIMAL(18,2), reason VARCHAR(200), BaseEntity)`；`service_assess.deduct_amount` 保留为**汇总冗余**（=Σ明细，写入时同事务回填）；R-STL-02 服务结算取数改 **Σ明细**（口径不变、粒度变细）；**应付非负校验**：Σ明细 ≤ 应付基数，超出拒绝。

**AC**：①登记 2 条明细 → deduct_amount=Σ 且结算取数一致；②明细Σ超应付 → 拒绝；③明细行删除后汇总同步；④既有服务结算回归（单条 deduct 兼容读取）。

## A6 SKU 标准价选填（S12）

**PRD 依据**：PM-08 L503（"**参考价必填，标准价选填**；标准价留空时采购流程使用参考价"）；L520-521。

**裁决**：`sku.standard_price` 改 **nullable**（保存/导入校验放宽：仅 reference_price 必填 ≥0）；**取价逻辑三处统一**：申请默认价 / 订单默认价 / 合同默认价 = `standard_price 优先，NULL 则 fallback reference_price`。最低价自动同步开关（全局配置）→ **P4**，不在本批。

**AC**：①标准价空、参考价 100 → 三处取价均 100；②标准价 90 → 取 90；③导入仅参考价 → 成功；④两价均空 → 仍拒绝。
